# Local Research Brief Hooks

## Positioning

Gistcaster turns local files and explicitly approved URLs into compact Markdown
briefs with the sources kept visible.

## Short Hooks

- "Research handoffs are easier to trust when the source list travels with the
  summary."
- "A local-first brief generator for agents that should not make hidden network
  calls."
- "Turn scattered notes into source-linked Markdown packets before planning,
  triage, or idea qualification."

## Demo Beats

1. Show `examples/local-brief.md`.
2. Run `bash demo/run-local-research-brief.sh`.
3. Open the generated brief and point to the source metadata.
4. Mention that URL bodies are metadata-only unless `--fetch-url` is supplied.
